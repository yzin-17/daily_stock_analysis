## 1. 目标与范围

DSA 收敛为 ThesisLedger 使用的数据服务，负责获取、标准化、校验、缓存和提供新闻、行情及其他已经纳入正式数据合同的事实。AI 推理、研究编排、观点与报告、账户业务和用户通知由 ThesisLedger 负责。

最终交付包括纯数据运行入口、新闻数据合同、客户端与原生分析产品代码的移除，以及相应依赖、镜像、脚本、CI 和文档调整。不能仅用配置隐藏入口后宣布完成。

本规格拥有 DSA 的实现语义；ThesisLedger 的消费、研究产物及交互由配套规格拥有。Compose、更新脚本和部署兼容清单仍由 `thesis-ledger-infra` 维护。

## 4. 数据服务设计

### 4.1 运行入口与依赖

建立专用 ASGI 应用，由 `server.py` 导出数据应用，目标启动方式为 `uvicorn server:app`。沿用现有服务名、内部端口和 `DSA_BASE_URL`，在 `/api/v1/thesis-ledger/*` 挂载 `dsa-data-v1` 和 `dsa-control-v1` 接口，以及 `/api/health`、`/health`。OAuth 回调与必要运维接口按已验证调用清单保留。

新应用只装配数据配置、数据存储、Provider、数据任务和认证。原生 `/api/v1/analysis`、Agent、历史报告、组合等路由不再注册；既有协议退役响应按兼容合同保留，不能回退到旧产品接口。

数据配置与存储必须形成可独立导入的闭包。Provider-specific 配置仍在对应适配层，公共模块隐藏路由、缓存、超时与标准错误。禁止将全部旧配置复制成新的杂项模块。保留现有配置值、密钥引用、持久化位置和策略修订语义；不进行整库转换或清库。

凭据兼容检查覆盖环境变量、持久化加密配置、OAuth 和实际 Adapter 的配置读取。用相同的受控配置比较迁移前后解析结果；不能仅断言函数没有抛错或来源目录仍存在。依赖导入失败必须在门禁中暴露，不能以返回空字典通过“缺凭据”分支。测试不输出秘密，不改变来源开关或准入。

生命周期保留公告运行时的启动/停止、OAuth 会话关闭及现行目录任务的租约/恢复。原生 `RuntimeSchedulerService` 退出后，这些职责仍由数据应用明确装配。D0 已确认股票索引被数据 Provider/标的解析消费，必须保留刷新和取消。现有本地种子位于 apps/dsa-web/public/stocks.index.json，删除客户端前由 D2d 保全到数据源码资产，保持原字节、生成入口、缓存回退与远端来源。

正式 MA/MACD/RSI 当前通过 StockTrendAnalyzer 间接依赖旧 Config 与决策 Schema，须先由 D2e 分离纯计算内核；Longbridge 的 SDK 语言参数保留，但数据 Adapter 不再导入产品报告语言模块。不改算法、预热、缺值或既有种子口径。

在未安装 LLM SDK、未提供模型凭据、没有客户端构建目录的隔离环境中，应能启动、鉴权、返回目录，并执行实际的数据读取和数据任务。除了静态扫描，还要检查已导入模块、后台任务与出站调用，证明没有分析或通知副作用。

### 4.2 新闻数据合同

新增 `/api/v1/thesis-ledger/market/news` 查询能力，通过现有能力注册、路由与控制合同提供。DSA 规格是新闻生产语义的事实源，ThesisLedger 的 Zod/客户端消费实现遵守同一组版本化合同样例。

| 部分     | 约束                                                                                                                       |
| -------- | -------------------------------------------------------------------------------------------------------------------------- |
| 请求     | 规范证券标识与市场、可选发布时间窗口、`limit`（1～50）、分页游标、`requestId`；不接收账户持仓、私人研究问题或任意模型指令  |
| 返回状态 | `available`、`partial`、`unavailable`；成功执行且没有结果时允许 `available` 与空列表，检索失败不能伪装为空列表             |
| 新闻条目 | 稳定条目标识、标题、原始 URL、发布方、检索 Provider、原文摘要、关联标的、来源条目标识或内容指纹                            |
| 时间     | `publishedAt`、来源明确给出的可见时间、`fetchedAt` 分开记录；未知发布时间保持 `null`，抓取时间不补作发布时间或历史可见时间 |
| 元数据   | 合同/解析版本、实际来源和路由修订、数据质量、缺失原因、分页与覆盖说明；Provider 秘密不得进入响应                           |
| 失败     | 沿用 V3 的准入、缺凭据、限流、超时、上游失败区分；未获准路由必须为零上游尝试；不绕过策略调用原生分析取数回退               |

检索只获取事实与源文，不请求生成式答案。文章内容按不可信外部数据处理。供应商原文摘要与后续 ThesisLedger 生成的摘要必须能区分。按来源 URL/条目标识去重，不把转载渠道数当成独立证据数；证券同名、跨市场代码和发布时间缺失有定向测试。

N1 固定能力名 `NEWS_SEARCH`、信封 `version=3`、合同 `news-search-v1`。DTO 位于 `src/services/thesis_ledger_news_contract_v1.py`，通过 `thesis_ledger_news_capability.news_capability_contract()` 复用现有 `CapabilityContract/QueryBinding`；声明本身不登记来源或装配运行路由。请求仅接受规范公开标的、发布时间闭区间、1～50 条、游标与至多 30 秒的总请求预算，禁止账户、持仓、Prompt 等额外字段。结构身份不代替证券目录核验或来源准入。

条目保存原始 URL、已知原始出处、来源条目标识、内容指纹与 `sourceUrls`；稳定条目身份绑定实际 Provider，转载按原始出处或内容指纹共享 `evidenceGroupId`。保留不同转载的出处时，独立证据数仍只计一组。去重只规范 URL 身份，不丢原始引用。`summaryKind=provider-excerpt` 表示源文摘录，原文中的工具指令或伪造引用始终只是字符串数据。

响应显式保存实际来源/策略/路由/凭据修订、上游尝试次数、已检查/返回/独立证据数、未知发布时间与缺失原因。`coverage.basis=current-search` 的完整仅表示本次查询与分页完成，不赋予历史全覆盖或 PIT 资格；有后续游标、截断、未知时间或部分失败时必须为 partial 并保持完整性为 false。成功空列表需要成功检索和实际尝试；unavailable 保留错误；未准入必须零尝试。配置加载失败使用 `configuration_failure`，不伪装缺凭据。发布、来源可见和抓取时间独立，未知保持 null，显式时区与窗口边界由合同核验。

版本化公共样例由 `contracts/thesis-ledger/news-search-v1.samples.json` 唯一维护；消费侧 T1 固定同一版样例，变更时核对内容指纹。样例均为受控合同输入，包含成功、空、部分失败、未知时间、请求歧义/来源歧义、未准入、转载、闭区间、分页及不可信源文，不代表任何真实来源已准入。

首批只承诺有合法可用来源的当前新闻检索，不宣称历史全覆盖、严格 PIT 或回测资格。路由与缓存键包含标的、市场、窗口、分页、来源/策略/凭据修订和合同版本。新增来源仍需独立准入与正向消费证据。

N2 的执行层复用既有七种搜索 Adapter，只装配选定来源；SearXNG 必须有专属实例，不使用公共实例发现。HTTP 尝试以实际传输计数，总预算预留执行回收时间；预算不足时零尝试返回超时。Bocha 明确关闭生成式摘要。公开身份先读取已发布且 checksum 有效的 Catalog 同代码条目，再读取现有数据索引；市场/资产类型冲突、代码不存在或无法唯一核验时在取数前返回 `ambiguous_instrument`，不以同名记录替代。Catalog 只读，不创建数据库或生成 fixture。显式控制凭据为空时不回退环境凭据；检索窗口最多向来源请求近一年，更早起点保留 `search_window_exceeds_one_year` 与不完整状态。

2026-10-22 的官方 RSS 接入规格已[归档](../../../thesis-ledger/docs/archive/specs/2026-10-22-free-news-dg3.md)，该来源已[退役](../../../thesis-ledger/docs/archive/specs/2026-11-09-remove-nvidia-news.md)。当前不提供其注册、路由或准入入口；历史新闻与冻结证据保留。共享宿主准入工具见[操作指南](../guides/local-runtime-tools.md)。

同日按用户“现有来源优先”的顺序，依[现有来源规格](../../../thesis-ledger/docs/specs/2026-10-22-existing-source-news.md)补充 `akshare / eastmoney / CN / STOCK / NEWS_SEARCH`。当前 SDK 只返回搜索第一页十条，提供公开元数据及转载页链接，保持有限覆盖、未知原始地址/可用时间及独立准入。`600519.SH` 的目标 V3、Market、Web 与原数据保护见[增量证据](../evidence/2026-10-18-data-only-service-news-contract.md#dg3-existing-source-20261022)。

后续按[HiThink 与 Yahoo 规格](../../../thesis-ledger/docs/specs/2026-10-22-hithink-yahoo-news.md)，新增 HiThink 个股新闻精确绑定并保留现有 HMAC/当前快照。CN 新闻采用 HiThink 首源、AKShare 备用，`600519.SH` 的目标 V3/Market/Web 与保全通过。[当时实源记录](../evidence/2026-10-22-hithink-yahoo-news.md)保留 Yahoo Search 可读和旧 Ticker 新闻路径 404 的验证结论。

本轮按[Yahoo 新闻接入规格](../../../thesis-ledger/docs/specs/2026-10-22-yahoo-news-dg3.md)增加既有 `yfinance / yahoo-search-news / US / STOCK / NEWS_SEARCH` 绑定。复用 Search.news，核验引用股票及每条新闻的关联代码，保留近期有限列表、秒级发布时钟和未知来源可用时间；网络、缓存、版本与精确准入保持有界。目标更新及 DG3 消费仍由[本次任务](../../../thesis-ledger/docs/archive/tasks/2026-10-22-yahoo-news-dg3.md)验收，原 DG3 与研究发布的边界保持。

市场快讯按[独立规格](../../../thesis-ledger/docs/specs/2026-10-22-market-flash-news-dg3.md)使用 `NEWS_FEED/news-feed-v1`，不改个股合同：财联社 `cls/cls-roll` 为全市场电报，见闻 `wallstreetcn/wallstreetcn-a-stock` 为 A 股频道。公开 DTO 明确 `market: CN` 消费范围、条目证券关联为空；内部 `CN.STOCK` 只作市场准入标识。复用现行策略/控制代次、有限准入、总预算和返回前检查；具体实源与保全见[证据](../evidence/2026-10-22-market-flash-news-dg3.md)。

N3 经当前数据 Runtime 的精确策略、来源快照、准入范围与返回前校验执行。七种新增来源默认关闭，首次仅保存设置也维持关闭；新闻路由须明确启停，注册与环境凭据均不自动启用来源。需独立准入的 QueryBinding 核对实际 Adapter/来源及内部凭据 HMAC，环境值变化时有效策略与执行资格同步失效；HMAC 不进入公开响应。备用来源只取自显式策略，共享原请求的剩余预算；保留主来源失败及各来源实际尝试，不将备用成功升级成无缺口的 available。读取中途撤销时丢弃结果，已发生的请求保留计数，以 `upstream_failure` 表达失效，避免伪造未准入零尝试。

新闻缓存仅重放相同业务请求的 available 响应，保留原始抓取时间与尝试事实；标识包含完整请求（含 requestId）、公开身份、精确目标、策略/来源/Adapter/凭据与控制代次。每个 Runtime 最多 64 项、1 MiB、60 秒；部分/失败结果不缓存，缓存前后仍检查当前控制事实与总预算。认证 POST 返回固定新闻 DTO（业务不可用仍保留 DTO）；缺少 Data token 为 401，非法/私有字段为 422。该路径的受控独立 HTTP 证明由 N3c 所有，DG1 的完整数据矩阵、DG3 的目标实源消费各自保留。

### 4.3 存储与任务保留

删除前列明每个数据库/目录/表的所有者、生产读写者、持久化用途与保留方式。保留 Provider 配置、凭据、目录、缓存元数据、公告原件及任务状态；报告、聊天和旧业务数据原样留存，不由新服务继续生产。

已确认的汇率拆分必须独立完成：将 FX 取数、直接/反向汇率查询和写入归入数据模块，复用 `portfolio_fx_rates` 的现有列、唯一键和数据库位置。数据入口不再实例化 `PortfolioService`、`PortfolioRepository` 或初始化全部原生业务表；不得为改名而复制整套组合仓储。保留 `as_of` 上界、过期判断、身份汇率、反向换算、来源和时区未知语义。现有无时区 `updated_at` 仍不能被补成可信 `fetchedAt`。新数据库只初始化所需数据表；旧数据库副本须能读写原缓存，原生业务表原样留存。若发现原有语义缺陷，另立数据合同修复，不在剥离中静默改变。

数据采集任务仍按其现行租约、重试与终态合同运行。纯数据服务重启后须证明未完成数据任务可恢复、重复启动不会重复采集提交，异常不会产生无限重试。不得以“没有原生分析 scheduler”为由关闭公告准备和数据更新。

既有搜索取数代码及数据诊断先解除对原生配置/分析层的依赖并保全，再移除其产品调用方。该保全是删除前置；新增新闻 V3 路由及真实来源验收是独立增量，不作为现有数据服务完成隔离的前置。

### 4.4 收藏项目对照中的数据保全要求

跨仓参考点与证据由[逐项实现对照](../../../thesis-ledger/docs/reviews/2026-10-18-starred-project-implementation-coverage.md)的 REF01/REF02/REF04/REF11/REF12 和配套 T0R 管理；本仓 D0 只承接涉及现行数据运行的依赖与回归。没有完成全部参考核查不阻塞已有数据隔离，但采用具体上游实现前必须补齐该点证据。

按受影响能力核对：精确市场/资产/周期/复权与真实上游身份；量额/比例/币种单位；报告期、披露/修订、来源时间和抓取时间；缺值、真实零、空结果、截断和完整性；缓存/凭据/路由修订及总请求预算。财务或基金持仓的分母与披露覆盖不得借字段重命名改变。估算净值不混入正式 NAV；查询接口不隐式宣称订阅。到达页数/行数上限须传播截断/覆盖元数据，不能因返回列表就宣称完整。派生指标须保留实际输入的不可用状态与全部参与计算的时钟；不能在服务瘦身或批量缓存中把它们丢弃。IR09/IR10 的现行内核修复由 ThesisLedger 所有，不由 DSA 删除叶代收。

同品牌不同端点不能直接沿用单位结论，不同 SDK 包装同一上游也不能宣称独立备源。腾讯 688 已有单位处理，689 仅为待同端点取证项；不能为补表格自动改转换系数或恢复停止的实源验证。HiThink SDK、a-stock-data 等宣称的能力不自动进入保全基线，现行支持以生产精确绑定和消费者为准；新增财务/估值/指数/宏观等另作范围决定。

G1 联通发现的腾讯 ETF 单标报价保全缺口由 D2f 修复：保留 Native `tencent/tencent` 的精确来源别名，将该端点已经明确提供的 CNY/unknown/unknown 单位经标准 QuoteResult 投影到 HTTP。缺失或不匹配时拒绝，不从证券代码填币种，量额继续 null。对应 Adapter 修订为 `tencent-etf-basic-quote-v2`，上游协议不变；其他未声明单位策略的来源保持原未知状态。主仓研究材料资格不因该修复而放宽。

借鉴 vn.py/指标框架的接口或生命周期时，仅保留数据用途；不将下单网关、策略执行、模型、报告或客户端重新引入纯数据服务。`hello245m/free-stockdb` 明确排除，不接入、不验证、不列为本方案依赖；原业务数据仍按 §4.3 留存。

## 5. 切换、兼容与上游维护

顺序为：盘点 → 数据配置/FX/存储与入口隔离 → 受控数据语义联通 → 纯数据构建、CI 与 infra 载荷准备 → 分批删除产品代码及其专属引用 → 最终依赖收敛 → 目标更新 → 留存与故障恢复验收。新闻沿独立的合同/Adapter/API/消费链推进。

删除前先使 Dockerfile、CI 与正式脚本不再要求待删除文件；每批同步处理其专属测试、语法检查、工作流与活动调用方。DSA 与 infra 的配套修订记录为一个可部署组合，不发布只更新其中一仓的组合。数据合同和恢复测试不得因产品测试退役而被跳过；保留确定性指标的参数/预热/缺值、完整窗口与增量对齐断言，不能因为测试原属分析目录而一起删除。完整镜像仅在组合稳定后构建，构建准备不代表目标已切换。

DSA、ThesisLedger 与 infra 对齐 `dsa-data-v1` 和 `dsa-control-v1`。先交付生产者，再启用新闻消费者。能力目录未声明新闻可用时，消费侧展示不可用。重大数据合同变化须独立升版并维护兼容矩阵。 [具名 V1 切换规格](../../../thesis-ledger/docs/specs/2026-11-24-named-v1-cutover.md)

最终镜像不包含客户端构建阶段、原生 AI/Bot/报告代码及专属依赖；数据 SDK 必需的编译链继续保留。依赖、Dockerfile 和启动命令变化必须通过 infra `./scripts/update.sh dsa` 完整更新，不能用快更代替。`sync-code.sh dsa` 随之改为纯数据载荷并继续执行兼容预检。

回退使用切换前可恢复的源码/镜像基线及原持久化数据，通过正式脚本操作；不依赖临时可写层，不删除卷。数据存储形态保持兼容，若盘点发现必须变更结构，先单独形成保留数据迁移叶和验证，再切换。

上游后续按数据 Provider、解析、时间/质量修复逐项评估移植。每次记录上游提交、受影响合同和回归证据；不将合并整个上游作为常规更新方式。此变化会增加选择性维护成本，需要以边界检查防止客户端或 AI 依赖重新进入数据运行链。

- DA4：新闻合同支持真实来源读取、规范化、去重、未知时间、分页/覆盖、失败与零尝试拒绝，并被 ThesisLedger 正向消费。

## 7. 验证策略与未决项

定向测试先证明配置、存储、路由、认证、新闻语义与独立导入；再执行 DSA 后端门禁；随后做独立进程 HTTP 联通，最后通过正式脚本验证目标镜像、既有数据消费者和恢复。静态扫描不能替代启动与副作用检查，离线新闻样例不能替代真实来源。

D0 已形成[静态依赖与逐路径矩阵](../evidence/2026-10-19-data-service-dependency-inventory.md)。产品代码按反向拓扑逐个闭合子集移除，强连通分量共同变更；不能把按目录编排的父项完成状态当成组内依赖图，也不能遗留悬空导入。该矩阵不是运行或删除完成证明。

D0 为每条受影响路径登记市场、Adapter/凭据方式、缓存与存储、准入/错误分支、受控用例及对应实源证据。既有正式支持的范围不能用“一只股票成功”替代；仅在外部来源、参数和实际输入未变时复用其证据，并补做变更后的数据入口与消费者验证。未开放来源保留原状态，不用可用性探针冒充该来源正向消费。目标更新、数据留存、故障/回退和新增新闻分别记账；其中一个通过不替代其他门禁。

本轮 DG2a 按用户授权，在保留数据及真实模型暂停的范围执行正式更新与受控验证；来源、额度和权限维持原状态。后续实源和恢复门禁仍按原依赖单独验收，不自动启用、购买或探测来源。

没有需要用户先回答的产品方向问题。技术前置为 DA1 的完整盘点；如发现无法保留的状态或仍在使用的产品入口，停止受影响删除叶并修订方案。默认保留全部旧业务数据，物理清理不属于本方案。
