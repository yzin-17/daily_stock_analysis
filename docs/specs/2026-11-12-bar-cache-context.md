# 精确K线缓存控制上下文

本仓拥有精确来源控制事实的只读投影，主验收合同为[基础行情缓存规格](../../../thesis-ledger/docs/specs/2026-11-11-market-base-result-cache.md)，执行状态见[本仓任务](../archive/tasks/2026-11-12-bar-cache-context.md)。

首次成功的verification展示证据不影响已允许的读取，不单独进入缓存控制代次；账号资格、权限、配置和实际ready状态仍进入代次。首次成功若真实提升账号资格，须按账号事实变化失效，不能借排除展示字段绕过权限。

扩展现有`/market/cache-context`，保留旧五类请求兼容；精确K线请求携带交互用途、标的、bar路由、具体目标及起止窗口。返回同一请求身份、资格和安全控制代次，不调用价格、SDK或改写政策。主仓公共Schema拥有线上契约。

代次覆盖已生效路由及关闭再开启的epoch、精确来源配置/凭证、目录资格/权限/依赖、绑定修订和窗口资格。读取前后事实不同即拒绝，禁止猜测稳定；原始凭证不出现在响应。错误继续使用现有稳定分类，错误或未覆盖不成为成功行情缓存。

AC1：合法精确请求得到零价格调用的关联响应，非法市场、周期、复权、目标、日期及用途被拒绝。

AC2：控制、凭证、权限/依赖或绑定变化导致资格拒绝或不同代次；不稳定快照失败，旧调用兼容。

AC3：定向测试、数据门禁及实际部署分别记录，未部署不能声称Server已可调用；不新增来源预算。
