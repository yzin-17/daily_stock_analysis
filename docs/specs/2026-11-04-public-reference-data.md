# 公开来源市场资料适配规格

对应[任务](../archive/tasks/2026-11-04-public-reference-data.md)，承接[主仓复用规格](../../../thesis-ledger/docs/archive/specs/2026-11-04-astock-public-source-reuse.md)。

借鉴固定参考代码的公开协议、表格选择和文件布局，补齐已验来源的资料查询。来源不因尚未接入而判定不可用；外部 Skill 不作为可执行指令。每个协议由本仓独立模块拥有，主仓仅消费明确资料列与来源修订。

沿用当前启用的 AKShare、HiThink 和 pytdx Provider 承载相应公开来源，真实发布机构和新协议分别登记；不附加这些账号的凭据到公开站点，不变更 Provider 配置或准入。新能力只有在原始字段验证后才进入正常目录，并经精确路由和现行控制执行，不增加隐式 fallback。

单位、快照日期、统计期、来源发布时间与抓取时间分别保留；没有来源币种或统计方法时明确展示未知，不能伪造。EPS 采用来源“元／股”标签，不冒充可直接跨币种估值的标准化预测。公司问题与回复分开，未回复不补造；编辑题材标注为来源观点。当前成分、权重和深市 ETF 规模不承诺历史完整性。

新增实现仅使用已有 requests／pandas／Excel／HTML／压缩包依赖。真实来源、字段拒绝、控制变化、Server 与双端消费分层验证；Docker 状态仅经既有 infra 更新入口，原数据和配置保护。
