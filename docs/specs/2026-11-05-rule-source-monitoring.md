# 官方收费来源版本监测规格

对应[任务](../archive/tasks/2026-11-05-rule-source-monitoring.md)。产品及跨仓验收由[主仓规格](../../../thesis-ledger/docs/specs/2026-11-05-rule-source-monitoring.md)持有。

本模块只拥有监测SQLite、任务执行和公开资料摘要，范围是现有官方收费包及三条ETF收费包。资料包注册表为显式本地路径，外部URL从包中受信文档解析，Control不接受URL。文件读取不改原包、不复用凭据库、不触发Provider调用或规则采纳。

已核验为同一官方文档的轻量正文可在监测目录中按完整 URL 精确映射，原地址与映射地址均须通过既有安全校验；资料包的原始 URL、摘要与冻结事实保持原值。文档 `04-15081` 统一读取 govinfo 的 HTML 正文，三个美股来源共享一次读取。`SR-FINRA-2020-032` 的两个引用来源读取该提案的联邦公报官方公告正文 `2020-23141`，保留原提交PDF及附件证据；公告正文包含所需2024年TAF规划表。新正文建立独立版本基准，旧 PDF 失败与观察继续保留。替换范围、资源保护及真实验收见[轻量正文规格](../../../thesis-ledger/docs/specs/2026-11-15-rule-monitor-lightweight-document.md)。

港交所`LSD/086/2022`的三个来源改读同日同修订的官方正文摘要及附件入口，监测标题注明范围，不认证原PDF签署与附件全文未变。SEC`34-106409`改读同一通知的公报HTML`2026-19392`；附加登记来源同样执行地址安全校验和精确映射。美国现行规则按需核验使用新URL的人工核验摘要，原PDF旧成功不能认证新正文，未核验地址、正文变化及缺少快照继续拒绝通过。原始冻结输入与费率保持原值。

SFC征费提醒`CT/053/14`的两个来源使用同通告的港交所标准`CT05314B.pdf`地址，替换原无后缀读取入口。未找到已核验且更轻的同通告HTML全文，标准PDF保持完整中英文正文及参与者准备指示，文件与原包核验指纹相同；不宣称大小缩减。原无后缀地址、原包与失败历史继续保留，新地址建立独立监测基准，现有连接及资源保护不变。

数据库保存配置修订、任务状态／attempt／owner／lease、资料版本及文档观察；领取与终态原子化，最多一次执行，过期任务终止，进程恢复不重发已开始外部请求。未创建任务时不调度；创建默认24小时，执行时间可在主仓自动化中调整。手动请求持久入队，数据读取失败与任务缺失区分。

来源选择按同一次登记目录快照核对成员资格和去重；每轮覆盖所选来源的全部去重文档，数量随目录扩展。跨仓验收由[来源选择规格](../../../thesis-ledger/docs/specs/2026-11-15-rule-monitor-source-selection.md)与[执行规格](../../../thesis-ledger/docs/specs/2026-11-15-rule-monitor-execution.md)持有。整轮300秒、每件2MiB、单件读取最多15秒、串行处理、无重定向及自动重发、0 USD。后台逐件落库并释放结果；超时后剩余文档记录预算耗尽而不发请求。HTTP错误和非文档响应保留最后成功值。摘要变化保留前后值，重复相同值不生成新版本，不发送外部通知。正文摘要只表示变化候选，不自动变更执行规则或历史可知性。

公开文档连接阶段最多5秒，读取、写入及连接池等待各最多10秒；外层15秒单件与整轮剩余预算继续优先。港交所印花税`CT/158/23`仍读取原官方通告PDF，FINRA交易活动费FAQ仍读取完整官方HTML，未找到已核验且更轻的同一文档版本；不使用其他通知或局部摘录替代，也不改变登记目录与原资料。

测试分别覆盖状态机、网络和正文、生命周期与认证HTTP；真实文件和目标部署独立留证，不能用本地假服务器代替实际可达性。

## 逐次执行历史与自动化读取

2026-11-09起，监测库结构版本2通过新增 `run_metadata`、`run_failures` 和历史索引增量升级，保留全部既有配置、任务、观察及版本。新任务分别记录手动或定时触发；逐项失败与观察结果在同一事务、同一有效执行条件下保存，后续恢复不覆盖过去原因。版本1历史的触发方式标为未知，逐项原因缺失时明确说明历史未保留。

Control 的只读 `GET /history` 接受 `offset>=0`、`1<=limit<=100` 和 `issuesOnly`，按创建时间及标识倒序返回总数、运行事实及逐次失败。仅异常包含部分不可读、失败及中断，认证边界不变。查询不触发检查或修改调度。

主仓自动化模块通过 Market 的只读契约聚合任务和执行历史，DSA继续独立调度，不能建立第二套执行任务。跨仓实施与验收由[统一自动化记录规格](../../../thesis-ledger/docs/specs/2026-11-09-rule-monitor-automation.md)持有。

## 执行计划与页面归属

监测库结构版本3新增 `schedule` 表，保留全部旧事实。已有非空来源配置保留启停并建立默认24小时计划；未创建的配置不投影成已创建任务。`POST /task` 首次创建默认启用、24小时后到期；再次保存只更新来源，保留原时间与启停。`PUT /schedule` 只修改计划、时区与下一次运行，两者均受配置修订条件保护。

默认 `@every24h` 采用实际24小时间隔，其余使用 `croniter` 验证、计算五段 Cron；时区来自保存的 IANA 标识。到期入队和下一计划推进在同一写事务中完成，已有活动任务时等待；不逐次补跑停机错过的计划。手动运行不移动计划时点；来源更新保持计划，重新启用过期计划时计算未来时点。配置及计划读取使用同一事务快照。

规则检测页只创建或更新任务来源，执行时间仅在自动化编辑中设置。主仓的[执行时间规格](../../../thesis-ledger/docs/specs/2026-11-09-rule-monitor-schedule.md)持有跨仓验收；不新增调度器，不改变历史记录、版本或规则采纳语义。
