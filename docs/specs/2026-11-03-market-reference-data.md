# 市场资料事实合同与执行规格

日期：2026-11-03。对应[任务](../archive/tasks/2026-11-03-market-reference-data.md)，消费合同由[主仓规格](../../../thesis-ledger/docs/specs/2026-11-03-market-reference-data.md)拥有。

本仓实现 `market-reference-v1` 的严格请求／结果、受控资料列、来源投影及精确执行绑定。Provider、原始协议与来源单位归本仓；主仓不复制上游解析。统一结果只承载可引用的事实，不生成观点、分数或交易建议。

通过现行 Control 有效政策与 Provider 配置读取来源，资料类型映射独立 capability；源身份、证券、日期、版本、引用与字段不符即拒绝。执行前后重新关联政策／Provider／绑定修订，明确失败和真正无记录。已配置来源不自动代表所有能力可用，也不自动扩展历史准入。

来源按财务、估值、东财公开事件、快讯和分笔等职责分模块；复用现有 SDK 会话、HTTP 条件及独立进程超时，不复制分析备用链或全市场 fallback。没有依赖或数据库结构变更；禁止写账本或原业务状态。新类型通过独立解析、控制语义和真实请求验证后才登记。

完成条件：本地边界验证、当前 Control 路由真实执行、目标 Server 合同联通、源和业务保护证据均满足对应范围；主仓双端 UI 验收独立维护。


## 当前目录

当前交付 63 类资料：原 29 类的验收继续有效；[公开协议适配](2026-11-04-public-reference-data.md)新增 FR／FDR、沪深 ETF 份额、中证／国证成分与权重、央视元数据、沪深问答、通达信 HTTP 盘后包、同花顺来源 EPS 汇总／机构预测与编辑题材、人民银行社融、统计局 PMI 和中债曲线，共 18 类；[衍生品适配](2026-11-04-derivative-reference-data.md)另增加五所期货日行情、四所会员排名、新浪期货报价／日线及 A50、ETF 期权近月链／报价／Greeks 与可转债，共 16 类。原 47 类来源回执通过当前合同，未重读旧源。来源字段和取消状态见主仓[当前复核](../../../thesis-ledger/docs/archive/reviews/2026-11-04-astock-derivative-reference.md)。

衍生品只扩展 Data 资产身份：期货 `FUTURE`、期权 `OPTION`，可转债沿用 `CONVERTIBLE_BOND`；Bar 身份范围维持原合同。主仓与本仓的 63 类标签、列、单位、日期、代码作用域、来源修订及资产身份须逐字段一致。

新 EPS 类型只展示来源明确年度和“元／股”单位，不编造 ISO 币种或来源未给出的统计窗／机构去重方法，不等同跨币种标准化预测。旧东财 `REFERENCE_REPORT_EPS` 不因此重新注册。行业排名保留既有真实连接失败事实；申万公开分类文件因宿主与目标 DSA 的证书链校验失败，本轮取消，未关闭 TLS。未接入本身不作为不可用的依据。

原有新闻、研报元数据、行情、来源启停与准入语义保持。新增日历使用独立上游标识，不能污染既有见闻快讯的能力字典。来源保存的自定义传输设置不能被适配器忽略；不支持时在出站前明确拒绝。
