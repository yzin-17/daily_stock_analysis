# 竞技场公开网页搜索规格

关联主仓规格：`../../thesis-ledger/docs/specs/2026-11-12-autonomous-model-arena.md`。

## 目标与边界

为竞技场只读研究提供认证的 `POST /api/v3/thesis-ledger/research/search`。按比赛市场选择 `WEB_SEARCH` 独立功能路由，复用现有搜索来源、固定凭据快照、来源启停和有界子进程。各市场使用 STOCK 路由槽表示研究用途，内部市场范围标识不作为证券身份或检索条件。

`WEB_SEARCH` 默认关闭，须由用户在数据路由中明确选择来源并开启。已有 NEWS_SEARCH、NEWS_FEED 及其授权不自动转为网页搜索授权。比赛另有网页搜索开关；两层条件都满足后才取数。来源失败保留稳定原因，不启动公共 SearXNG、不扫描环境并隐式切换来源。

## 请求与结果

请求包含市场、检索词和最多十条结果。结果保留实际来源、观察时间、标题、链接、摘要及来源原始发布日期（可缺失）；不将抓取时间当发布日期，不将搜索结果当成交价格。搜索窗口上限为近一年，返回覆盖说明。总执行预算十二秒，来源执行进程必须回收。

## 验收

- [ ] 认证、输入范围和请求结果关联。
- [ ] 关闭、未选路由、凭据缺失、来源失败和超时分别返回不可用。
- [ ] 控制版本或凭据变化阻止发布晚到结果。
- [ ] 受控来源验证端到端装配和子进程回收。
- [ ] 真实来源与部署单独验收，不由离线测试替代。
