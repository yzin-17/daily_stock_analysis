## 验收契约

- AC1：保留用户明确指定的请求日期与逐年分段，不采用本轮实测漏掉当日的次日结束或SDK扩大窗口。不复权时 `_var` 与 `param` 均使用空复权字符串，携带锁定SDK的 `r` 参数并使用requests默认请求头，匹配16:52实际成功请求。业务日期采用闭区间，原始响应只视为候选数据；单日、跨日、跨年均在本地严格裁剪，不补零或伪造完整历史。
- AC2：请求数量640与原始响应资源上限641分离；641是本次已观察到的有界兼容范围，不宣称腾讯保证最多多返一行。仍限制响应字节、原始行数、年度分段数、整窗行数和总期限，超限拒绝而非截断。范围外数据不能进入业务结果。

本规格对[完整周期窗口规格](2026-10-05-tencent-period-window.md) AC2中原始单响应640行限制作局部修订；业务整窗3650行、最多16段、逐段SHA256、分页证据形状与当前协议身份保持兼容，不据此认证覆盖完整或重新授予来源准入。若实施必须改变这些稳定边界，应先修订本规格。
