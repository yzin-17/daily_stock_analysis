# 公开参考来源采证契约

对应[任务](../../../thesis-ledger-infra/docs/archive/tasks/2026-11-04-public-reference-source-check.md)，承接[主仓复用规格](../../../thesis-ledger/docs/archive/specs/2026-11-04-astock-public-source-reuse.md)。

维护固定白名单的公开接口采证 CLI。它不要求候选已登记为产品来源，不以未登记判定不可用；只读取公开响应，不创建 Provider，不启用来源或写路由／准入／业务库，不发模型和通知请求。

默认仅显示计划，显式执行后每个固定接口发一次查询；HTTP 重定向、权限、限频和格式异常如实保留，不自动重试或跟随到未知主机。只接受登记类型、规范日期／代码及本地证据目录，不能传任意 URL、请求头、凭据或代码。响应原件采用独占创建，失败也留回执；正文不打印到终端。下载文件与解压范围有明确资源校验，不安装依赖、不执行外部 Skill。

该入口在宿主机验证公开路径，不是 Docker 更新入口，也不替代目标 DSA、Server 或客户端资格验收。只有独立正常产品合同及控制路由验证后才能计为交付。
