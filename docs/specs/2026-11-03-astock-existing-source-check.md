# 既有 A 股来源采证维护契约

日期：2026-11-03。对应[任务](../../../thesis-ledger-infra/docs/archive/tasks/2026-11-03-astock-existing-source-check.md)，承接[主仓条件交付规格](../../../thesis-ledger/docs/archive/specs/2026-11-03-astock-existing-sources-delivery.md)。

提供固定来源样本采证入口，目标是当前本地 `desktop-linux`／`thesis-ledger-dev` 健康 DSA。复用现有目标身份和维护锁，运行前后核对镜像、挂载、现有 Provider 状态与只读数据保护。入口不替代应用更新，不创建容器，不安装依赖，不变更正常策略、准入、凭据或业务数据。

仅接受登记的样本类型及规范证券／日期，不接受任意代码、地址、请求头或新增凭据。每次执行固定最小单页／单标的查询，实际源请求和协议失败完整记录。来源状态未启用或真实上游不属于既有来源时在出站前拒绝；按已保存配置使用原传输条件。公共接口不使用无关继承凭据。

离线测试覆盖输入拒绝、目标身份、来源限制、响应身份／字段、失败与空态、出站计数和原配置保护。采证只证明对应字段与窗口，不修改正常能力资格；产品合同和消费由主仓／DSA 的独立任务维护。

## 合格资料路由追加

合格合同与实际消费者实现后，`../thesis-ledger/scripts/local-runtime/market-reference-routes.mjs` 先生成可审查计划，再以该计划调用独立应用模式。只追加已登记市场资料能力的单一精确目标，逐项明确启用；现有全部路由保留。Python 仅以只读 SQLite 连接采集 DSA 计划；应用通过前端同一 Server 策略 API 及其 `expectedRevision` 条件写入，保持 Server 期望配置与 DSA 生效投影一致。执行前后核对 DSA 身份、原策略和 Provider／准入指纹，拒绝计划生成后的状态变化。来源必须已配置、启用且当前绑定和依赖可用；不新增账号、不写凭据、不续期准入。

应用模式须提供计划绝对路径、输出绝对路径以及目标确认 `thesis-ledger-dev/reference-routes/append-only`。输出采用独占创建，不覆盖历史证据。原策略本身未启用、同名路由已存在但不同、指纹变化或绑定不合格时均拒绝写入。


### 本轮取消后的路由撤销

原轮行业排名真实调用未满足可用性条件，东财研报 EPS 缺逐条币种及旧年年度依据，按用户授权取消那两条接入。计划仅可列出精确的 `REFERENCE_INDUSTRY_RANKING` 或 `REFERENCE_REPORT_EPS`／`akshare`／`eastmoney` 原样单目标路由；应用必须额外提供首次执行计划 `--owned-plan`，证明该路由确由原轮创建且不属于原有路由。清理与新增资料仍通过 Server 条件写入，任一同名路由被用户修改时拒绝清理。该取消不等于永久判定上游不支持。原轮目录为 29 类；[公开参考协议](2026-11-04-public-reference-source-check.md)后继新增 18 类，当前合计 47 类，旧采证白名单并未随目录自动扩展，原路由不受撤销逻辑影响。
