# 行情读取兼容与来源校验

实施见[任务](../tasks/2026-11-27-upstream-market-reader-followups.md)。

- AC1 Yahoo 兼容日线按交易日闭区间读取，报价历史回退使用未复权价格，缺少前一根日线时昨收保持未知。具名 V1 沿用精确窗口和来源时间。
- AC2 efinance 股票和 ETF 批量缓存只接收非空有效行情，市场宽度对其专属字段继续校验。坏响应后下一次请求可以恢复，精确报价使用单标快照。
- AC3 TickFlow 报价批量按同一凭证、有效端点和操作的已验证容量拆分，未知时使用单标。缓存只接收本批唯一、现价有效的记录。容量探测占用股票报价权限检查的一个请求名额，并复用草稿隔离。首次验证单标，后续在该请求内逐次扩大样本，直至配置或样本边界。多标的参数拒绝保留仍适用的较小已验证容量，后续检查缩小试样。请求限频沿用现有冷却。
- AC4 核对富途 OpenD 的进程超时与恢复、AkShare 现有生产调用边界，以及 TickPlus 独立接入所需的安全传输和协议依据。ETF 报价准入、真实账号和目标环境另凭实际证据确认。
- AC5 TickFlow 沪深 ETF 精确报价以当前凭证单标读取，校验证券代码与报价字段，保留来源时钟及未经单位换算的量额。股票报价批容量仍由股票检查单独取得。
- AC6 TickFlow 沪深 ETF 精确日线接入 `1d/none`，先通过免费端点核对当前证券元数据，再在同一连接读取闭区间日线。量额保留原值，当前证券元数据不证明历史时点身份。报价和日线分别用 `510300.SH` 通过 DSA 数据 API 真实读取验收。
