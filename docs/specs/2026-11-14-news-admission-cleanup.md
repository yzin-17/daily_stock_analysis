# 新闻准入工具残留清理

## 目标与边界

完成已退役官方新闻来源的宿主工具清理。原数据源删除遗漏了 infra 的共享准入入口；这些入口随后迁移到本仓，仍有旧来源默认值、专属分支与失效导入。

将共享工具及测试改名为 `scripts/local-runtime/news-admission.*`，仅保留 AKShare、同花顺、Yahoo、财联社及华尔街见闻配置档。CLI 必须显式提供 `--source`，不选择新的默认来源。Python 的数据库辅助函数必须显式接收路由与目标。

现有确认参数、证据摘要、有效期、扩展、续验、并发保护、目标身份与卷校验保持。两个同花顺入口同步改用通用模块。历史新闻、冻结记录、历史回执、迁移清单、来源政策和业务数据库保持原样；本次不调用上游、不应用准入、不更新 Docker、不创建提交。

## 验收标准

- AC1：两个应用仓及 infra 的当前源码、脚本和配置中无旧新闻来源的支持分支、失效导入或旧文件名引用；专用文件名仅存在于历史资料。
- AC2：五个保留配置档仍可生成计划；缺失、重复或未知来源在读取证据前拒绝；Python 同样拒绝未审阅来源。元数据、目标及 SQLite 并发保护通过离线验证。
- AC3：同花顺消费者导入成功，扩展和续验测试通过；当前指南与合同使用新入口。已退役来源的旧规格归档且引用有效，冻结回执与历史迁移原件不改写。

## 验证依据

使用包含未跟踪文件的 `rg` 搜索，不以 `git grep` 代替完整工作树扫描。运行 Node 参数及消费者检查、Python 准入和 SQLite 测试、DSA 来源目录与运行合同门禁、文档链接及差异检查。仅宿主维护工具发生变化，目标服务部署和浏览器验证不适用。
