# 来源推荐元数据与只读盘中采样

## 所有权与边界

来源注册层拥有上游归属和推荐依据；复用现有精确读取绑定与凭证快照，提供有界、无业务写入的盘中采样。移除应用主动休眠及本地频次计数，保留 SDK 保护、超时、重试退避、熔断、权限检查冷却和资源并发上限。现有缓存及 TTL 不变。

跨仓契约与完整验收见 `../../../thesis-ledger/docs/specs/2026-11-10-routing-recommendation-and-intraday-probe.md`；本仓执行状态见[任务](../tasks/2026-11-10-provider-recommendation-and-intraday-probe.md)。

## 本仓验收

- 目录新增可选推荐元数据，绑定真实来源而不是根据 Provider 名称猜测；未知保持未知，元数据进入目录修订。
- 采样只读取已启用且满足配置、依赖、权限和准入的绑定，不修改业务政策、权限记录或业务事实。北京时间 11-11 中港 10:05 起、美股 23:05 起各四批，每来源每市场最多十二次逻辑读取。
- 仅比较相同市场、完整标的、周期、复权和 K 线身份的 OHLCV，不用请求时钟或观察时间变化制造数据变化；输出原始确认字段，未知不推断为最终发布。
- 脚本限制查询范围与重试；遇明确权限、额度或限频停止相应来源。报告不含凭证、原始异常原文或完整上游响应。
- 移除等待后保留限流、额度、认证和权限错误分类，保持既有失败、取消、超时、关闭与实例生命周期行为。
- 离线受控测试先通过，今天不进行新的真实来源读取；两市场真实采样分别保留验收缺口。
