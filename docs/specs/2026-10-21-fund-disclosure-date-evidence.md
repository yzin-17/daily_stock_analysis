# 基金披露日期证据的 DSA 适配

这是 ThesisLedger 原基金披露门禁的来源叶，合同字段和时效事实源为[主仓 Spec](../../../thesis-ledger/docs/specs/2026-10-21-fund-disclosure-date-evidence.md)，执行及验收见[本仓归档 Task](../archive/tasks/2026-10-21-fund-disclosure-date-evidence.md)。本仓只拥有标准结果、Eastmoney 投影、受控公开参考和 API 转换，不定义另一套消费规则。

现有季度观察继续保留 `disclosure_date=None`。仅当精确基金、季度和观察持仓逐项符合已核对公开参考时，附加可选日期证据；未知时分保持未知，保守可用边界单独保存。未登记参考保持未知，参考失配明确区分，损坏不得静默降级。

初始参考为 `161725.OF/2026-Q2`，从正式报告和管理人披露公告核对；正文引用、来源字节摘要、原比例与实际核对时刻随参考登记。它是版本化来源输入，不是缓存或测试结果，允许 SDK 返回严格匹配子集但不增删/归一原观察。

不增加配置项、Provider、路由、SDK 请求、存储升级或模型能力。真实网络资格与本地合同测试分层；目标只通过同级 infra 维护入口更新，保留数据和现有开关。旧 V3 消费者在未识别新增证据时仍按未知披露安全降级。
