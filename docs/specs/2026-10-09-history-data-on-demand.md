# 股票历史状态按需读取

日期：2026-10-09。主范围以 [ThesisLedger 规格](../../../thesis-ledger/docs/specs/2026-10-09-history-data-on-demand.md) 为准。

## 读取边界

复用现有 BaoStock 会话、代码转换和结果读取器，按实际沪深股票及明确区间读取日级 `tradestatus/isST` 与交易日历。保留每个已知字段；缺行、空值、重复冲突和日历缺口分别保留未知，不根据价格或成交量推断状态。不支持 ETF、北交所或日内状态，不改变旧整窗可交易性合同。

规范化输入绑定证券、查询区间、实际观察时钟、查询字段、修订及规范化响应 SHA-256。ST 仅为粗标记，不推导细分风险或精确价格限制；覆盖已知状态与 ST 分别表达。当前读取不提供历史当时可见性。

后续复用现有能力目录、Control 主备路由与缓存；不替用户保存配置，不直写准入。结构化响应在消费合同中使用独立来源引用，不伪装 PDF/公告。

## HiThink 股票研究读取接缝

显式 `assume-untradable-no-bar` 的 HiThink 股票 none/qfq 固定来源研究复用现有核验后的现行日历。来源缺价格行按原研究假设披露，不能证明停牌；BaoStock 状态独立冻结并决定明确停牌日不成交。当前上市日期缺失仍未知。普通完整覆盖入口保持逐会话要求，ETF 和历史可见性边界不扩展。价格适配器保留原证券、调整口径、日期、数值和分页校验，现行 API 再按日历检查实际日期与逐日缺口。


## 基础日期接续

按实际单证券调用既有 `query_stock_basic`，复用日期解析，保留 ipoDate/outDate 各自已知、未提供、非法或来源不可用状态；摘牌日不是最后交易日。查询响应独立摘要/实际观察时钟与消费窗口绑定，附到既有结构化状态响应并以新缓存修订隔离。当前基础资料只用于固定来源研究，不赋予历史可见性。基础日期失败只披露该能力缺口；不推导停牌起点、上市初期规则或精确价格限制。


基础日期接缝已实现：按单证券 query_stock_basic 保留 IPO/摘牌日期、独立状态与当前观察摘要；日级状态组合和缓存修订已接入，原日期/状态测试及新测试通过。当前尚未作目标部署与真实读取，不能据此标记生产消费完成。


日级状态与基础资料在同一次已有SDK会话内读取，保留独立摘要和观察时钟，总期限仍45秒。基础日期失败的组合不写长时缓存；日状态和基础日期的生产能力、特殊窗口价格能力分别报告。

## 摘牌窗口的供应商错误语义

HiThink历史接口业务码1002并不总是格式错误：现行600112两窗口的原始message为精确`Unknown thscode: 600112.SH`，同参数日期600221成功。只有业务码1002且原始message与当前请求证券精确匹配时，按既有`symbol_not_found`分类；不将来源未知证券推导为全体退市历史不支持。其他1002保留原格式错误分类。只返回重建的安全说明，不将上游正文或凭证复制到错误。错误分类集中于供应商适配层，不改标准请求、日历、价格覆盖、口径或用户主备。

## HiThink分红的显式研究语义

用户选择将原始字符串"2"解释为“实施方案已公布”，不是供应商已核实的数字枚举或现金已支付。仅显式`hithink-plan-announced-v1`研究参数启用：保留原进度、协议版本、研究假设依据、每10份原始金额和独立日期，生成方案观察，不直接生成经济事实。默认入口的数字进度拒绝、文字实施事实和不完整覆盖合同保持；其他未知值拒绝，冲突记录拒绝。现金生产消费由主仓D2及后续准备/冻结合同唯一拥有。

全空占位必须具有全部10个业务字段且全为null，其他字段有非空值时不接受为空。规范化可跳过并记录忽略数；传输只对显式研究参数下的count0/单条全空占位作已确认兼容，保留原响应摘要、原条数与忽略数，不将其他计数冲突吞掉，不将零有效事件视为完整零分红。来源覆盖始终未知。

## D3：标准方案观察读取

现有鉴权market/events传输增加显式known-cash-observations-v1合同，仅完整选择主仓D2规则、境内ETF/CNY范围时使用。复用D1的单证券有界读取和数字进度研究解释，输出通用方案记录，不返回支付事实/准入或完整覆盖。查询绑定为request-bound-query-v1，币种依据为explicit-research-scope，历史身份notVerified；端点无身份/币种回显时不冒充已验证事实，后续准备/冻结/结果必须披露此依据。来源/规范化版本、原响应摘要、实际观察、非敏感配置/HMAC凭证修订和占位数保留。

供应商读适配器只消费已固定凭证；控制入口独立拥有有效策略/目标顺序、目录、Provider启用/删除/配置/依赖与凭证快照的读前后检查。普通完整事件准入和旧入口保持，不写准入或重新执行取消的全历史PDF证明。DSA只对已保存精确目标执行，不自行换源；策略或凭据变化拒绝，来源失败不返回零记录。预案不作为已公布方案计入，保留排除原因；未知进度仍拒绝。

## D4-FD：只读控制身份复核

主仓共享`known-cash-control-v1`合同在现有鉴权market/events上独立分派，完整请求范围/研究规则/精确目标/版本及expectedControlIdentity均必需。控制快照及通用安全异常归`thesis_ledger_known_cash_state_v3`，已知资料读取和只读复核共同消费，不复制校验规则；供应商字段解释留原适配器。只读复核不调用方案读取器或供应商，核对前后有效策略/完整目录/目标顺序、Provider配置及凭证快照/HMAC，当前身份与预期一致才返回verified及实际完整目标顺序。checkedAt为当前复核时刻，与研究截止分开，不回填资料。

配置/HMAC差异、目标/策略/目录变化、禁用/依赖/额度或撤回鉴权分别保留安全失败原因；未知处理器不能验证。响应不含凭证、分红记录、覆盖或准入；旧资料读取/完整事件合同不变。发布样例由主仓合同生成，DSA单仓测试从自身副本读取，组合测试核对一致。当前实施先做真实FastAPI/控制快照离线定向验证，正式更新和实际只读端点消费由主仓D4-FG单列验收。
