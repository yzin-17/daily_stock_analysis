# 首批备用来源语义核对规格

对应[任务](../archive/tasks/2026-11-04-reference-backup-qualification.md)及[主仓规格](../../../thesis-ledger/docs/specs/2026-11-04-astock-source-coverage.md)。本仓拥有同花顺财报三表、沪深官方两融／龙虎榜及新浪研报列表的来源语义与纯解析，依赖 infra 独立保存的实际原件。

本轮只交付读取样本的投影、异常反例和可替代性判断，不创建产品绑定、Provider、路由或历史库；原 63 类运行代码不因资格核对改变。采用现有 Python 依赖，不安装外部 Skill 或 SDK，不调用模型、通知或付费源。

每组先核对真实封套与身份，再冻结字段。金额、数量、报告期、披露日和交易日分别验证；未知币种、缺失金额或发布日期不猜测。官方全文与结构化记录、证券汇总与席位不得混合。新浪研报按当前最小元数据分别比较条目与分页；当前条目不要求评级／目标价／PDF，不能把这些完整研报差异当成最小合同缺字段，也不补造新浪没有的精确总数或日期窗口保证。

本地反例覆盖错误证券／日期、字段漂移、单位未知、来源错误与真空态区分；跨组仅复用已有稳定解析原语，不新增无业务所有权的公共杂物模块。实际读取失败的组保留语义未验，不能由夹具制造可用。

实源发现后冻结的边界：同花顺只用 `flashData.report`，不混入数值不同的 `fieldflashData`，保留“亿／万”显示值及舍入精度；上交所两融实际分页上限 2000，必须按真实总数读全两页，来源出现的 `689` 代码单独注明超出现有股票代码范围，不扩大产品合同。深交所 Excel 为元／股原值，JSON 目录按亿元／万元／万股显示并截去两位之后的小数；100 项原件对照已证实，须用明确截断规则核对，不能扩大误差容限使错误口径通过。

完成条件：四组分别具有实际尝试、可解析样本的纯投影和错误断言，以及相对于当前产品合同的字段矩阵；源文件和文档保护通过。Docker／Server／客户端不在本轮资格范围，不能声称已经产品启用。

四组已完成实际资格核对，当前差异和来源覆盖由[主仓结论](../../../thesis-ledger/docs/reviews/2026-11-04-astock-source-coverage.md)维护。本规格继续约束纯解析及离线核对入口，不以调查完成自动建立产品绑定。
