# 衍生品与可转债资料适配规格

对应[任务](../archive/tasks/2026-11-04-derivative-reference-data.md)，承接[主仓规格](../../../thesis-ledger/docs/specs/2026-11-04-astock-derivative-reference.md)。本仓拥有参考 Layer 9／13／15 的公开协议、源校验和投影，不在主仓复制解析实现。

合格来源继续由现有启用 Provider 承载，来源协议分别登记；期货／期权 Data Route 使用 `FUTURE`／`OPTION`，可转债使用 `CONVERTIBLE_BOND`，不扩大普通 Bar 合同。新类型的代码格式、单位、时间、分页和错误由严格资料合同约束，原 47 类保持兼容。Source 身份、有效政策、Provider 配置与修订仍需执行前后关联；保存的传输设置不能被忽略。

按来源分别实现日行情、会员排名、新浪报价／日线、ETF 期权清单／报价／Greeks 和可转债条款。日期见证、能源排除、Greeks 空列偏移、IV 小数、未来摘牌与未知状态为必要断言。完整性、源真空态和连接／权限／格式错误分别处理；不将来源报价自动转换为仓位、保证金、期权定价或账户风险。

新增代码使用现有依赖，公共 HTTP 不附带 SDK 或 netrc 凭据，不关闭 TLS、不自动绕过来源失败。完成条件为各合格类型本地语义、正常路由／真实 Server、主仓客户端和数据／配置保护通过；采证失败的候选按主仓条件处置，保留失败证据。

目标完整构建实际安装 AKShare 1.20.25，既有基金身份读取依赖 `fund_em` 偶然导出的 `demjson` 导致 API 导入失败。作为 D5 的前置兼容修复，基金读取直接使用相应 SDK 版本的 JSONish／旧 JSON 解码模块与请求头定义；不再依赖 `fund_em` 的传递导出，不改变来源端点、身份分类、响应原文摘要或读取预算。必须验证两个解码入口及目标真实镜像的 API 导入，不能关闭构建 Smoke 绕过。
