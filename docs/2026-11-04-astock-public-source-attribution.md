# 公开资料适配的代码借鉴与修改说明

本轮借鉴 [simonlin1212/a-stock-data](https://github.com/simonlin1212/a-stock-data/tree/bf447c1d05fa75eac907426601d602125c81a0cd) 的公开接口、请求参数、表格识别及文件布局实现。固定提交为 `bf447c1d05fa75eac907426601d602125c81a0cd`，`SKILL.md` blob 为 `4b4c8d76f37479416adeb232ffc0a09596925e1f`，原许可副本见 [Apache-2.0 许可](licenses/a-stock-data-LICENSE.txt)。

涉及 §1.3 通达信 HTTP 盘后包、§2.2 盈利预测、§3.1 编辑题材、§4.8 ETF 份额、§5 新闻联播、§9 ETF 期权、§10 沪深问答、§11 宏观及利率、§12 指数文件、§13 期货与大宗、§15 可转债。衍生品参考摘录对应固定 blob 第 4644～4724、5802～6576、6919～7002 行。盘后文件布局的上游还引用 [jing2uo/tdx2db](https://github.com/jing2uo/tdx2db)，本仓按公开布局重新实现校验与投影。

本地实现按协议分模块，接入既有 Data／Control V3 及 `market-reference-v1`。增加请求关联、源身份、单位／日期、空值、受控分页、总读取预算和配置变化保护。没有安装或执行外部 Skill 指令，没有复制其交易评分或自动执行逻辑。

有意修正：一致预期只选择明确的 EPS 表，不回退第一张任意表；来源未给的 ISO 币种和统计方法不补造；公司问答失败不返回伪空集合；编辑题材仅表示编辑标签，不照搬金额单位或因果结论；下载包不在文件系统解压，盘后包投影仍为股票／ETF。

衍生品另按独立来源实现：科创期权参数按实际标的回显修正为 `科创50`；排除月份列表首项的日历提示，Greeks 跳过真实空列并保留 IV 小数；ETF 期权按张与元／份展示，不按未知乘数推算金额。上期／能源以同日原件区分，中金所 CSV 与 XML 逐合约见证交易日，会员三套排名分开。期货连续线保留来源身份及换月限制，A50 不冒称具体 SGX 到期合约；可转债按来源单页读取，未来上市／摘牌及未知状态分别处理。具体合同见[衍生品资料规格](specs/2026-11-04-derivative-reference-data.md)。

首批备用来源资格核对另借鉴 §2.4 新浪研报列表、第7281行起官方两融及第7455行起备用源表／沪深龙虎榜的端点和布局。没有复制参考代码关闭TLS的部分，也未将其自动重试带入产品。实际补齐上交所2000条分页限制、深交所目录／Excel显示单位与截断差异、龙虎榜详情身份、财报公司数据块与显示精度，以及新浪明确迁移地址与逐条标题证券证明。四组仅作为资格纯投影，字段／分页是否可替代分别判定，没有自动启用或更换产品来源，见[备用来源语义规格](specs/2026-11-04-reference-backup-qualification.md)。
