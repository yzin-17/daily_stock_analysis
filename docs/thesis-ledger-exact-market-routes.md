# ThesisLedger 精确市场数据接入与配置

普通数据按用户选择的精确接口读取。选择与执行状态独立：缺凭证来源在前端主备下拉中禁用，已有配置仍保留；已提供逐功能账户检查的来源另按当前检查结果控制新选择。其他来源的停用、缺 SDK、接口额度不足和需高级证据状态沿原配置方式说明，读取时再校验实际条件。保存配置不会创建准入记录或伪造接口权限。

## 报价和其他普通数据

精确报价包括既有 AKShare、efinance、腾讯、pytdx、HiThink、Yahoo 接口，以及 AKShare ETF 东方财富单标接口、TickFlow 单标报价、Longbridge 港美股、Finnhub 和 Alpha Vantage 美股报价。ETF 单标读取固定完整交易所与代码，核对响应代码及可用的市场字段，不调用全市场 ETF 列表。Tushare 固定使用官方 `rt_k` 实时日线接口，`close` 是最新价格，需要该接口的独立权限；失败时不切换到旧新浪接口。

基金净值、净值历史、持仓和筹码仅登记现有实际读取器，净值日期必须来自上游，非法主结果在源边界被拒绝，备用源接管完整结果。Tushare 筹码按其实际接口登记；接口积分和权限由实际请求核验。

## 配置、检查和准入

- 来源清单的市场、资产、能力与上游名称统一由精确库存投影；RQData 明确列出两类事件能力，不再以空能力集合代替证据状态。Yahoo 仅显示当前应用已接入的 CN/HK/US。
- 页面凭证优先于环境凭证，字段按来源凭证定义验证。HiThink、TickFlow、Finnhub、Alpha Vantage 使用 API Key；Tushare 使用 token；Longbridge 保留页面 legacy/OAuth 流程。
- 必须先具备完整有效的页面或环境凭证才能启用需要认证的来源。缺凭证的启用开关禁用，服务端显式启用返回 422 / `PROVIDER_CREDENTIAL_MISSING`，事务不写入配置。完整凭证与启用可以一次提交；清除页面凭证且无环境凭证时同时停用。旧缺凭证配置按未启用展示，已保存路由继续保留。免凭证来源可直接启用。
- 配置就绪只表示来源已启用、必要字段完整且依赖已安装。连接测试与实际请求分别核验目标接口，某接口成功不授予其他接口权限。
- 缺运行依赖使用 `dependency_missing`，缺凭证使用 `credential_missing`。前端禁用缺凭证选项，配置完成后恢复；缺依赖等其他状态只作说明。保存层保留已有目标，不因凭证暂时缺失删除配置。
- 普通日线、报价等不再要求人工窗口准入；返回前重新检查策略、精确来源及凭证快照。环境密钥在版本号不变时轮换，也必须重建缓存适配器。
- 普通 HiThink 图表只展示来源实际返回的日期，不以本地已有上市事实或独立日历范围限制请求；该读取不生成完整窗口证明。完整窗口和回测继续使用严格证据分支。
- 高级事件完整覆盖、历史事实、身份映射、严格 PIT 和单位转换继续保留独立证据检查，普通报价成功不能替代这些检查。

## 全部来源精确检查

Tushare“检查功能权限”在凭证侧栏按六个现有精确功能分别显示可访问、当前账户缺少权限、凭证缺失/无效或权限待验证；保留禁用条目及中文原因。输入变更后旧草稿结论撤销，保存成功后用当前配置检查一次。只读测试请求使用 `purpose: "account_access"`，返回独立 `accountAccess`，不混入业务 `capabilityResults/routeResults`。每次最多六请求、每接口3秒、总预算18秒，无自动重试；正常配置的结果只在当前运行时内存保留5分钟，绑定Token、实际端点及配置代次，变化/过期/重启后待验证。刷新页面只读取当前状态，不触发供应商检查。

该检查仅说明本次接口请求被接受，空列表不证明历史覆盖、记录质量或无分红。网络失败、限频和坏响应保持待验证；`2002`按[官方HTTP协议](https://tushare.pro/document/1?doc_id=40)解释权限，`40203`须有明确权限拒绝内容。积分和独立接口权限不能相互推定，原Tushare现金真实消费外部剩余项保持；已有主备选择不会自动删除。

前端“测试连接”打开精确能力检查侧栏，可逐项选择市场、资产、上游及复权口径。`POST /api/v3/thesis-ledger/control/providers/{provider_id}/test` 可提交 `route: {key, target}`；不提交时仅按能力选择代表项。返回 `routeResults` 列出该来源全部精确库存、当前状态、是否实际读取、错误和实际检查标的；未选项为 `not_tested`，空结果不成功。

普通读取复用精确日线和报价分发；官方来源实际校验对应本地数据包；事件来源先核验当前准入及身份/日期映射。草稿凭证不能借旧账号的事件准入读取，也不能通过检查产生新准入。每次读取预算 8 秒，并限制四个后台读取；超时不会接收晚到成功。诊断不保存策略、凭证、健康状态或业务结果。

Longbridge OAuth 必须包含匹配 client ID 的完整令牌，只有 client ID 不构成配置完成。环境缓存或 Base64 值只读解析并进入不可变快照；账号/令牌轮换会改变快照，诊断中的刷新不写回页面凭证。RQData 继续使用页面用户名/密码与独立事件证据。

Yahoo 报价固定单标 Yahoo 响应并核对标的和可用的资产类别；Longbridge 固定单标 SDK 响应并保留缺失量额与真实零值，不请求静态信息或历史数据来补字段。两类报价本地适配/来源修订为 `v2`；底层平台算法修订仍不由此推定。

上游没有提供成交量或成交额时保留 `null`。图表价格仍可显示，量额指标显示缺失，周期聚合保持未知；依赖量额的回测冻结拒绝缺字段，不生成 `volume×close`、零或字符串 `"null"`。

## 验证边界

隔离 SQLite/HTTP 与 SDK/HTTP 替身测试验证精确参数、保存意图、凭证变化、返回身份和失败路径。真实账号和目标部署分别验收。主仓 Spec/Task 与报告：`docs/specs/2026-10-07-market-route-user-choice.md`、`docs/tasks/2026-10-07-market-route-user-choice.md`。

接口核对依据包括本机安装的 SDK，以及 [Tushare rt_k](https://tushare.pro/document/2?doc_id=372)、[Alpha Vantage 官方说明](https://www.alphavantage.co/documentation/)、[Longbridge Python SDK 说明](https://longportapp.github.io/openapi/python/reference_all/) 和 [efinance API](https://efinance.readthedocs.io/en/latest/api.html)。价格口径始终保留来源定义，无法证明的其他口径不登记为支持。

## 本地历史资料展示元信息

内置公告与公开规则资料通过来源清单的 `sourceKind: local_history` 与逐来源 `localHistory` 提供展示信息。元信息直接读取适配器使用的九个 JSON 文件，包含数据集身份、收录标的或交易范围、实际起止日期、原始文档标题／链接／发布日期，以及 `updateMode: bundled`。读取失败时保留资料分类并省略缺失元信息，由客户端明确回显。

来源与路由选项按停复牌、风险警示、现金分红等通用类型命名。公司属于公告内容及实际收录范围。客户端“检查资料包”打开原始公告与规则文档列表，按原文链接归集多种用途并保留关联资料；读取诊断使用独立的“检查读取能力”操作。原文发布日期缺失时明确显示未提供。

该信息用于分类与覆盖提示，读取和准入仍由原有入口检查，不扩大数据覆盖。现金分红资料的实际区间为 2023-01-03～2023-02-01；单次事件日期、报告年度与实际覆盖日期分别保留各自语义。
